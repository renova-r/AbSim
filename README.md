# AbSim

Simulates the development of antibody repertoires over time.

Compatibility updates by Renova.

Makes the sample-time class checks return a single condition and structures the author metadata.

## Installation

```r
install.packages("AbSim", repos = c(
  Renova = "https://renova-r.r-universe.dev",
  CRAN = "https://cloud.r-project.org"
))
```

Version `0.2.6.9002` is based on [CRAN 0.2.6](https://cran.r-project.org/package=AbSim).
